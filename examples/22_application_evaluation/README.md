# 22 Application-Level Evaluation

These examples evaluate application results with ordinary fixtures, Actions,
Flows, ExUnit assertions, and offline model responses. Jido core does not add
an Eval API or runtime.

## Examples

1. [Datasets and deterministic scorers](22_01_datasets_and_scorers/README.md).
2. [Offline model judge](22_02_offline_model_judge/README.md).
3. [Tool trajectory and budgets](22_03_trajectory_and_budgets/README.md).

Every scorer states what it measures and what it does not prove. No live
experiment is part of the suite.
